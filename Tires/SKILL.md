# Tires (TV Series) — Subtitle Translation Background

## 基本信息
- **剧集标题**：Tires（中文译名：《轮胎》/《轮胎店》/暂译《Tires》）
- **类型**：职场情景喜剧 / 工作场所喜剧
- **创作者**：Shane Gillis、Steve Gerben、John McKeever
- **首播平台**：Netflix
- **首播日期**：2024年5月23日（第1季）；2025年6月5日（第2季）；第3季定档2026年8月13日
- **季数/集数**：第1季6集、第2季12集（共18集），第3季在制作中
- **单集时长**：20–23分钟
- **制作公司**：Dad Sick Productions
- **原版语言**：英语（美式英语，费城/宾州口音特征）

---

## 世界观与核心设定
- **地点**：美国宾夕法尼亚州韦斯特切斯特
- **核心场所**：Valley Forge Automotive Center（谷福汽车服务中心 / 谷福汽修厂）——家族经营的连锁汽修店其中一家分店，经营不善、濒临倒闭
- **核心冲突**：堂表兄弟（或表兄弟）Will 试图振兴店面，却遭表哥 Shane 持续骚扰、破坏、拖后腿
- **基调**：低成本、即兴感强、粗俗幽默、观察式喜剧、类《办公室》/《老娘舅》风格但更粗粝

## 说话风格指南
- **Shane**：极度自信的废话文学、频繁打断、自称“老板”实则啥不干、费城白人工人阶级口音（元音前移、硬R）、大量脏话、性/种族/体型梗、即兴感极强
- **Will**：被动吐槽、长叹气、试图专业却被打断、句式相对标准但常被逼无奈
- **Cal / Dave**：蓝领粗话、简短有力、Cal 更冷嘲热讽、Dave 更跟随 Shane
- **Kilah**：干练、直接、女性视角吐槽、偶尔加入胡闹
- **Phil (S2)**：富二代/老钱作风、大手大脚、说大话、与 Shane 父子相声般互动
- **整体**：大量重叠对话、即兴感、非标准语法、频繁“like / I mean / you know”、字幕需保留口语节奏、脏话按分级策略处理（保留/替代/省略）

## 文化背景与翻译提示
1. **费城/宾州蓝领文化**：修车店是典型家族小生意，强调“手艺、忠诚、面子”；Shane 的行为严重违背蓝领道德（不干活、拖后腿、搞破坏），这是笑点核心
2. **美式情景喜剧传统**：单镜头、无笑声轨道、类纪录片感（虽非访谈式）、集数标题多双关
3. **Shane Gillis 真人原型**：单口喜剧演员，曾因种族梗被 SNL 解约，风格极具争议；剧集延伸其舞台人设——**“冒犯但自知”**
4. **Netflix 发行**：全球同步上线，字幕需兼顾美式俚语与跨文化可读性
5. **季度跨度**：S1 2024、S2 2025、S3 2026，角色关系随季深化（如 Phil 入主、店面命运）
