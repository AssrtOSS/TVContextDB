## 世界观与核心设定

- **时间线**：接在原版 *S.W.A.T.* 第8季结局约 **两年** 之后。原版结局时 Hondo 仍率领 20-Squad；本剧开篇 Hondo 已被迫退休。
- **核心冲突**：一场高曝光任务失利导致致命枪击案，Hondo 事业受损被迫退休。LAPD 高层为挽救濒临取消的 S.W.A.T. 项目，强行启动“实验性编制”，拉回 Hondo 组建一支 **“最后机会”实验小队** —— 成员皆为部门内无处安置的**年轻边缘警员**（Gen Z），形成 **Gen X（Hondo）对决 Gen Z（新队员）** 的代际张力。
- **季度主线**：除每周案件外，贯穿全季的 **阴谋线** —— 警界高层暗中针对 Hondo 与 S.W.A.T. 编制，且新队内**藏有内鬼**。
- **基地设定**：洛杉矶 LAPD Metropolitan Division，延用原版音stage与战术装备风格；片头沿用 1975 版经典主题曲。

## 语言风格与口吻指南

| 角色 | 语言特征 | 字幕处理建议 |
|------|----------|--------------|
| **Hondo** | 短促有力、指令式、偶尔夹杂街头黑话、称呼队员用姓/昵称 | 保留军警简略语法；对年轻队员称呼可用 “Rookies”“Kids” → “新兵”“小子们” |
| **Jude** | 叛逆、挑衅、碎句多、爱用 F-word（美剧分级 TV-14 允许） | 保留冲击力，脏话按分级酌情保留/替换 |
| **Ethan** | 极度字面、缺乏隐喻理解、专业术语密集 | 字幕保留专业术语，不加口语化修饰 |
| **Sammy** | 网络流行语、缩写、emoji 式口语、自拍式独白 | **慎用** 过时梗；若原文为 “slay / no cap / fam” 等，字幕用对应中文网络热梗（如 “绝绝子 / 没毛病 / 家人们”）并加注 |
| **Cassidy / Malik** | 介于专业与青年之间，偶有讽刺 | 标准警匪剧口吻即可 |
| **Deacon / Hicks / Tan** | 原版风格延续：Deacon 幽默温情，Hicks 官腔施压，Tan 硬核兄弟感 | 沿用原版 *S.W.A.T.* 字幕既定风格 |

## 文化背景与翻译策略提示

1. **续作非重启**：观众多为原版 8 季老粉，**保持术语/称呼/人名一致性** 高于一切。若原版字幕已有公认译法（如 “20-Squad→20小组”“Deacon→迪肯”“Hondo→汉多”），**严禁自创**。
2. **代际梗本地化**：Sammy 台词大量 Gen Z 梗，建议采用 **“动态等效”** —— 用当期中文网络同温层梗对应，并在首次出现处加 **术语表备注**（不显示在字幕内，供校对参考）。
3. **战术术语**：Stack up / Breach / Clear / Overwatch / Tango / Mike 等 **保留原版通用译法**（集结/破门/清理/掩护/目标/分钟），勿创新。
4. **LAPD 实务**：警阶、无线电十码、事件代码（如 211/245/647）沿用原版对照表。
5. **音乐/片头**：Barry De Vorzon 主题曲为 franchise DNA，字幕若出现歌词/哼唱，**保留原文或标注 [主题曲旋律]**。
6. **分级 TV-14**：允许中度暴力、强烈语言、部分性暗示。字幕脏话处理按平台成熟度分级规范执行（通常：F-word → “他妈的/操”；Shit → “见鬼/屎”；Damn → “该死”）。
7. **客串原班人马**：Deacon、Hicks、Tan 出场时的称呼、梗、过往梗（如 Hondo 叫 Deacon “Brother”“Partner”）需与原版 8 季字幕库完全一致。
