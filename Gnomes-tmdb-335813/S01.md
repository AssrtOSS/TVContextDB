## S01E02
侏儒女王失踪后，Arnold 调查镇上的破坏与失窃事件，并怀疑 Zayn 等少年。镇长承认挪用了议会资金购入女王，急于在记者 Brant Sanders 到来前寻回。Arnold 与 Ellie 争执后继续排查，Mr Henrickson 和 VideOzone 成为线索。

- 女王由德国博物馆购入；资金来自 council budget。保留挪用资金与节庆宣传的关系。
- Jenny 称 Arnold 为 Lucky；本集提出该昵称的来由问题，后续有解释。
- assessment Eloise 是 Arnold 对处于评估者角色的 Ellie 的调侃称呼，不能反转为 Ellie 对 Arnold 的称呼。

- Gnome-a-Palooza 为小镇节庆；不宜无依据限定为艺术节。

## S01E04
Harvey 的死亡被明确告知，Arnold 与 Ellie 因处置危机及此前隐瞒而发生争执。众人讨论如何对待侏儒 Stumpy，警局遭到更多陶制侏儒袭击。Devon 尝试恢复无线电通信；本集末，来自镇外的怪物猎人现身。

- Harvey 已死亡；Lachlan 在后续两集仍明确参与行动，不能将两者的命运混同。
- Signal One Milspec 1030 是 Devon 从《CSI》相关片段获得灵感的无线电型号。
- Stumpy 为单只侏儒的称呼；相关争论涉及是否应把所有侏儒一概视为敌人。

## S01E05
Dana 与 Gillian 说明女王、战斧 Bluttrinker 及童贞者触斧之间的诅咒规则，Arnold 开始石化。众人寻找战斧，讨论利用工厂窑炉毁斧。Arnold 与 Ellie 追查线索，并谈及他在峡谷救下骑车的 Jenny、留守诺普顿的往事。

- Helvetti 的 Virgin Queen、黑曜石战斧 Bluttrinker、女巫封印与诅咒是核心背景；冬至条件在后续回顾中再次强调。
- Josie 被安排去找 Tobias 启动窑炉；Lachlan 一行另行寻找 weedkiller。不要混淆各组任务。
- Jenny 与自行车、峡谷有关；救援经历解释 Lucky 昵称及 Arnold 寻求帮助他人的动机。对白未明确说明 Jenny 当时的心理目的。

- Lachie 为 Lachlan 的昵称；他提到消防员经历并驾驶旧车。Eloise 是 Ellie 的全名，此前数集已经出现。
