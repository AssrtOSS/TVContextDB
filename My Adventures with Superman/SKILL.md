# My Adventures with Superman translation context

# 《我与超人的惊奇冒险》字幕翻译背景

## 基本定位

- 英文名：*My Adventures with Superman*
- 推荐中文剧名：**《我与超人的惊奇冒险》**
- 类型：美国动画、超级英雄、科幻动作、成长、校园与职场喜剧、恋爱。
- 制作：Warner Bros. Animation、DC；动画主要由韩国 Studio Mir 制作。
- 叙事形式：连续剧式成长故事，不能把每集当作完全独立的单元剧。
- 作品基调：以年轻人的友情、恋爱、自我认同和新闻理想为主轴，动作冒险服务于人物成长。

> Max 部分地区页面使用《我和超人的惊奇冒险》，并采用“露薏丝·莲恩”“吉米·欧森”等译名。本项目统一采用大陆观众更熟悉、跨 DC 作品更稳定的译法：**露易丝·莱恩、吉米·奥尔森**。

### 关系处理

- **克拉克、露易丝、吉米**是全剧核心三人组：朋友、同事、调查搭档，也是连续主线的情感中心。
- 克拉克和露易丝的关系同时包含暗恋、恋爱、秘密身份和信任危机。两人称呼应随关系变化从正式、职场化逐渐转向亲密。
- 吉米是团队中的摄影师、信息传播者和气氛调节者，常以夸张表达、网络梗和即时反应推动场面。
- 露易丝与萨姆·莱恩之间存在亲情和价值观冲突：露易丝强调新闻调查与个人判断，萨姆强调军方安全和风险控制。
- 阿曼达·沃勒与萨姆·莱恩都把超人视为潜在外星威胁，但两人的表达方式不同：萨姆更偏向军事判断，沃勒更偏向冷静的机构化执行。
- 卡拉与克拉克的关系同时具有亲属、同族幸存者和价值观冲突三重性质。

## 世界设定

- **Metropolis：大都会**  
  现代化美国都市，新闻、科技、政府机构和超人事件的主要交汇点。
- **Smallville：斯莫维尔**  
  克拉克成长的堪萨斯小镇；涉及肯特家庭、农场和克拉克童年时，可保留英文地名音译。
- **The Daily Planet：《星球日报》**  
  露易丝、克拉克和吉米实习及工作的新闻机构。新闻采访、报道、线索和编辑流程是重要语境。
- **Krypton：氪星**  
  克拉克和卡拉的故乡。氪星文明、遗留科技、军事扩张和毁灭真相逐步展开，不宜在早期对话中擅自补全背景。
- **Kent Farm：肯特农场**  
  克拉克在堪萨斯的家庭住所，代表安全、亲情和普通人的生活。
- **Zero Day：零日事件**  
  与氪星飞船、外星入侵记忆及地球政府对超人类的恐惧有关的关键历史事件。
- **Project Cadmus：卡德摩斯计划**  
  政府或秘密机构相关的科技、实验和武器项目。根据语境译为“卡德摩斯计划”或简称“卡德摩斯”。
- **Checkmate：棋局**  
  秘密情报与安全组织。它与 Task Force X、政府高层和外星威胁应对体系有关。
- **Task Force X：X特遣队**  
  政府主导的特殊行动机构，主要目标是应对超人、氪星人及其他超人类威胁。若上下文明确涉及其高风险、可牺牲的行动人员，可参考“自杀小队”的 DC 传统背景，但不应随意替换剧中机构名。
- **Flamebird：火焰鸟**  
  吉米经营或参与的网络媒体／内容品牌。涉及社交媒体直播、粉丝和网络传播时，保留其品牌属性。
- **Amazo：阿玛佐**  
  与人工智能、复制能力和超人类技术有关的人工智能或机械生命体。不要译成普通的“机器人”后丢失专名信息。

## 整体剧情前提

故事围绕二十多岁的克拉克·肯特、露易丝·莱恩和吉米·奥尔森展开。三人在《星球日报》成为实习生后，逐渐组成调查报道团队：

1. 克拉克学习控制超能力，并建立“超人”这一公开英雄身份；
2. 露易丝追查大都会的军事、科技和政府秘密，逐步成长为调查记者；
3. 吉米以摄影、网络内容和朋友关系支持团队，同时寻找自己的职业定位；
4. 克拉克与露易丝的恋爱关系在秘密身份、新闻伦理和外星身世之间不断受到考验；
5. 随着零日事件、氪星遗产、卡拉、布莱尼亚克、阿曼达·沃勒和 X 特遣队等线索展开，故事从个人成长扩展到地球与氪星之间的历史冲突；
6. 剧集持续强调“英雄身份如何形成”以及“善意、信任和自由选择能否改变暴力循环”。

不要把本剧简单处理成“超人打败反派”的传统英雄故事。人物关系、新闻调查、秘密身份和氪星历史通常共同推动剧情。

## 说话风格

### 克拉克·肯特

- 日常状态：善良、紧张、容易语塞，偶尔自我怀疑；表达可保留停顿、改口和不完整句。
- 作为超人：语气更坚定、清晰、鼓舞人心，但仍应保留克拉克的温和与同理心。
- 面对家人和朋友：亲近、坦率，有时显得笨拙。
- 面对身世问题：从困惑、回避逐渐转向主动追寻。
- 翻译重点：不要把克拉克日常状态译得过分油滑，也不要把超人译成冷酷的军方英雄。

### 露易丝·莱恩

- 语速快、判断果断、追问直接，常带有调查记者的压迫感。
- 对新闻和真相高度执着，受到质疑时容易表现出防御性。
- 与克拉克相处时会出现害羞、嘴硬、试探和情绪化反应。
- 翻译重点：保持主动性和攻击性，避免把她弱化成只围绕超人展开的恋爱角色。

### 吉米·奥尔森

- 外向、活跃、夸张，常使用网络化表达和即时反应。
- 负责摄影、社交媒体和团队气氛，偶尔因兴奋而跑题。
- 与克拉克关系亲密，常用玩笑帮助克拉克建立信心。
- 翻译重点：可以适度口语化，但避免堆叠过时网络词；笑点应优先保持节奏和人物性格。

### 佩里·怀特

- 主编式命令口吻，重视效率、新闻价值和团队纪律。
- 语气可强硬，但通常带有职业责任感和保护下属的意味。
- “Great Caesar’s ghost!” 等夸张感叹可根据场景译为“我的天”“老天爷”等，不必机械直译。

### 阿曼达·沃勒与军方人员

- 冷静、简洁、机构化，常用风险、目标、资产、威胁、行动等词。
- 面对超人时倾向于去人格化，把他称作“目标”“资产”或“外星威胁”。
- 翻译应避免加入过多情绪词，保持命令、评估和控制感。

### 氪星人与人工智能

- 氪星相关对白可能带有仪式感、军事感或高度理性的抽象表达。
- 布莱尼亚克的语言应冷漠、精确、缺少普通人的情绪起伏。
- 卡拉的早期表达可能更直接、强势，随着与地球人建立联系，语气逐渐出现个人情感。

## 文化与风格背景

- 本剧将经典 DC 超级英雄叙事与少年漫画、少女漫画和现代动画喜剧结合。
- 动作表现受到《龙珠》等少年漫画影响，强调训练、能力升级、伙伴关系和情绪爆发。
- 恋爱与友情的重要性接近少女漫画：误会、秘密、告白、信任危机和关系修复与战斗同样重要。
- 作品借用了美国新闻业和大城市职场文化：实习、抢新闻、采访权限、编辑审核、署名和职业声誉都可能推动剧情。
- 露易丝的记者成长线体现了调查新闻、媒体竞争和个人伦理之间的冲突。
- 吉米的网络内容和社交媒体表达体现当代年轻人的信息传播方式；相关台词可译得自然活泼，但不要强行替换成具体中文平台名称。
- 超人传统中的“真相、正义和更好的明天”在本剧中被重新解释为：面对恐惧时选择善意，面对身世时保留自主判断，面对权力时坚持人的尊严。
- 本剧的科幻规则强调技术和外星文明，少用传统魔法解释。遇到能力、武器或能量现象时，优先使用科幻和工程语汇。
- 作品中的“外星人”既可能是客观身份，也可能承载政府恐惧、排外情绪和政治宣传。应根据说话者立场处理语气，不能把所有 alien 都译成中性或贬义词。

## 统一翻译原则

1. 角色首次完整出现时使用“中文名（英文名／身份）”的清晰表达，后续按中文名或称号处理。
2. Clark Kent、Kal-El、Superman 需要根据身份场景区分；不要把三个称呼混为同一称号。
3. General 在指萨姆·莱恩时译“将军”或“莱恩将军”；在普通军衔语境中译“将军”。
4. 机构、项目、事件和城市名称保持前后一致，尤其是“大都会”“星球日报”“氪星”“零日事件”“X特遣队”。
5. 新闻术语优先采用现代中文新闻行业表达，避免逐词直译。
6. 动作场景保持短句、命令感和节奏；情感场景保留停顿、犹豫和关系变化。
7. 不提前透露角色真实身份、氪星历史或后续反转；背景资料用于理解语境，不应替代字幕本身的叙事信息。
8. 本项目未找到 ID 800000 以下的匹配历史 ASSRT 字幕，因此没有可用于交叉确认的 ASSRT 旧译名。当前词表以官方 DC、Adult Swim、Max 页面及跨作品通行译名为依据；发现平台官方译名与本项目词表冲突时，优先维持本项目内部一致性。
