# Granite Harbour translation context

# 《花岗岩港》（Granite Harbour）字幕翻译背景

## 基本信息

- **英文名**：*Granite Harbour*
- **中文名**：花岗岩港
- **类型**：英国警务犯罪剧、剧情剧
- **主要地点**：苏格兰东北部城市阿伯丁（Aberdeen）
- **制作与播出**：LA Productions 制作，BBC Scotland、BBC One、BBC iPlayer 播出
- **结构**：每季 3 集，故事以独立案件为主，同时持续推进 Lindo、Bart 与警队成员的职业和私人关系。
- **季数范围**：截至第三季，主线案件依次涉及阿伯丁能源与商业圈、港口及毒品网络，以及郊外庄园和 Traveller 社群。

### 姓名与资料差异

- **Cora MacMillan** 有少数资料误写为 *Macmillian*；推荐统一为 **Cora MacMillan / 科拉·麦克米伦**。
- **Jaiyush Mallick** 在 BBC、部分数据库中也写作 *Mallic*；BBC 系列二资料使用 **Jay Mallick**，建议字幕中采用 **Jay Mallick / 杰伊·马利克**，正式全名首次出现时译作 **Jaiyush “Jay” Mallick / 杰尤什·“杰伊”·马利克**。
- **Lara Bartlett** 的职级随剧情发展可能变化；不要因后续升职而回译早期对白中的职务。
- **DC、DS、DI、DCI** 是侦探职务前缀，不是角色名字的一部分。

## 世界设定

故事发生在阿伯丁及其周边地区。阿伯丁位于苏格兰北海沿岸，是港口城市，也是传统渔业、航运、石油天然气和新兴可再生能源交汇的地方。

“Granite Harbour”同时呼应阿伯丁的两个地方特征：

1. **Granite City（花岗岩之城）**  
   阿伯丁因大量使用当地灰色花岗岩建造建筑而得名“花岗岩之城”。剧名中的 *Granite* 指向城市景观和地方身份。

2. **能源城市与北海港口**  
   阿伯丁长期被称为欧洲的石油与天然气中心。剧中常见油气企业、海上作业、货船、港口、能源转型和企业并购等语境。翻译时应保留“传统油气产业”与“可再生能源转型”之间的社会和经济张力。

3. **苏格兰东北部语言环境**  
   当地英语可能带有东北苏格兰方言 **Doric / North-East Scots** 色彩。Doric 并非标准英语口音；对白中的词汇、语序和发音有时会让外地角色或观众感到难懂。字幕不宜把所有口音都改成夸张的方言汉字，可通过少量口语化措辞体现地域感。

4. **多元人口与移民背景**  
   Lindo 来自牙买加并拥有英国军事警务背景；第二季出现伊朗难民与跨国航运、毒品网络。对白中会出现加勒比、南亚、中东、苏格兰本地和挪威文化交汇的情况。

5. **Traveller 社群**  
   第三季将案件置于当地 Traveller 社群及其周边社区。这里的 *Traveller community* 指英国、爱尔兰语境中具有独特历史与社会身份的流动人口社群，不能简单翻译成“流浪汉群体”。推荐译为 **Traveller 社群** 或 **旅行者社群**；涉及具体人物时根据上下文处理，避免带有贬义。

## 整体剧情前提

退役皇家宪兵队成员 Davis Lindo 来到阿伯丁，加入 Police Scotland 的侦探培训项目，目标是成为刑事侦探。第一天便被卷入当地石油大亨死亡案，必须在完全陌生的城市、警务体系和社会关系中证明自己。

随着剧情发展，案件从单一谋杀调查扩展到：

- 阿伯丁油气产业与能源转型引发的商业冲突；
- 港口、国际航运和跨国毒品网络；
- 警队内部的纪律、程序、信任与泄密问题；
- Lindo 与父亲及个人身份之间的矛盾；
- Traveller 社群、地方土地关系、财富阶层与社区压力。

主线并非单纯的“新人破案”故事。Lindo 的军事经验、快速判断和越权倾向，持续与 Police Scotland 对证据链、授权、等级和程序的要求发生冲突；Bart、MacMillan、Mallick 与 Monty 则分别代表指导、管理、竞争和数据分析等不同办案立场。

## 对白与说话风格

- **Davis Lindo**：受军事训练影响，表达直接、简短、行动导向；面对上级时常显得不够服从。情绪较深时会暴露身份、家庭和归属感问题。中文宜保持克制，不要翻成过度粗鲁的军人口吻。
- **Lara “Bart” Bartlett**：街头经验丰富、反应快、直来直往，常把真实判断直接说出来。与 Lindo 对话时节奏较快，带有同事间的竞争和熟悉感。
- **Cora MacMillan**：管理型、命令式、重视程序和责任边界。面对下属通常简洁明确，少用解释性长句。
- **Jay Mallick**：带有怀疑和讥讽色彩，尤其在与 Lindo 初次合作时。中文可用冷淡、略带刺的职场表达体现冲突，不宜加入过强的网络化语气。
- **Monty Montrose**：偏理性、技术化、信息密度较高；涉及数据、记录和调查线索时，字幕应优先保证逻辑清楚。
- **地方居民与警员**：部分人物带有苏格兰东北部口音或 Doric 词汇。遇到 *fit*、*quine*、*loon*、*bonny* 等地方表达时，应结合语境翻译，不必机械保留原词。
- **加勒比与移民角色**：注意身份、语域和口音差异，但不要用汉语地域方言替代英语口音。可以通过句式、词汇正式度和称呼方式区分人物。

## 翻译统一建议

- 地名 **Aberdeen** 统一为 **阿伯丁**；**Scotland** 统一为 **苏格兰**。
- **Granite City** 译为 **花岗岩之城**，不要与剧名“花岗岩港”混用。
- 角色首次正式介绍时可使用“职务＋姓名”，后续根据警队习惯使用姓氏或昵称：
  - **DC Lindo**：林多警探 / 林多
  - **DS Bartlett**：巴特利特警探 / 巴特
  - **DCI MacMillan**：麦克米伦总督察 / 麦克米伦
  - **DI Mallick**：马利克督察 / 杰伊
  - **DS Montrose**：蒙特罗斯警长 / 蒙蒂
- *Bart*、*Monty*、*Jay* 是昵称或常用称呼，保留昵称比每次使用全名更符合对白习惯。
- 英国警务等级不应套用中国公安职务体系；采用“警探、警长、督察、总督察”等功能性译法即可。
- *police HQ* 译为 **警察总部** 或 **警队总部**；*the station* 根据场景译为 **警局**。
- 对于 *mate*、*lass*、*wee* 等英国或苏格兰口语，应根据人物关系和语气灵活处理，避免逐词翻译造成突兀。
- 涉及 *oil*、*gas*、*renewables*、*offshore* 时，保持“石油、天然气、可再生能源、海上/离岸”的术语前后一致。
- 警务对白中的程序性表达应简洁、准确，避免为了自然中文而删去授权、证据、拘留和报告等关键信息。
