# Minimum Security (Surveillant !) — 字幕翻译背景资料

## 基本信息

- 标题验证：Minimum Security 为法国剧集 Surveillant !（直译“狱警！"）的国际发行英文标题，确认为电视剧集（喜剧系列），非电影。
- 首播：2026年9月16日，Disney+（法国及国际）；在美国通过 Hulu 上线（Hulu Original）。
- 播出平台：Disney+ / Hulu，Disney+ 法国本土原创（法语法语原创）。
- 结构：第1季共8集，每集约26–30分钟，2026年9月16日一次性全季上线；状态为"Returning Series"（已续订）。
- 主创：John Wax、Gauthier Plancquaert 创作，John Wax 执导；Nabi Productions 制作（联合 UGC、Les Films du 24）。2026年戛纳国际电视剧节（Canneseries）展映。

## 世界观设定

故事发生在虚构的法国谢努瓦兹（Chénoise）看守所（maison d'arrêt）。与传统监狱题材相反，镜头始终停留在狱警一侧：囚犯是“工作环境”而非叙事主角。该剧采用伪纪录片（faux documentaire）手法，以职场喜剧的形式呈现监狱日常：管理层与一线狱警靠即兴发挥、歪打正着的决定和层出不穷的馊主意维持秩序。剧集背后触及法国现实的监狱议题：人满为患、经费不足、“惩罚还是改造”之争。

## 整体剧情梗概

科琳·马拉尔（Corinne Maillard）以近乎“入侵式母亲”的姿态管理谢努瓦兹看守所的拘留区：她坚信每个囚犯都值得第二次机会、监狱可以让人变好，为此不惜说谎、操纵；同时她还要照看一群比囚犯更难管的狱警。日常运转靠混乱中的平衡勉强维持。转折点：与科琳早已断绝联系的儿子被关进了她本人管理的监狱。她的职业信条瞬间变成最私人的拷问——她一边继续管理监狱和下属，一边设法与儿子重建关系。

## 人际关系

- 科琳 ↔ 杰夫：上下级；科琳行事凭直觉，杰夫凡事讲规章，是天然的喜剧反差搭档。
- 科琳 ↔ JP：科琳默许 JP 的“自由式”管教，因其与囚犯建立的信任正是她理想主义的实证。
- 科琳 ↔ 斯特凡妮：导师与被她收进门下的新人。
- 科琳 ↔ 儿子：全剧核心情感线——狱长与关押在自己监狱里的亲生儿子。

## 语言与说话风格

- 整体为快节奏职场喜剧对白，伪纪录片采访镜头（直接对镜头说话）与其他场景交替。
- 科琳：温暖、强势、略带控制的“母亲式”语气，关键时会理直气壮地狡辩（mauvaise foi）。
- 杰夫：一本正经的官腔，引用规章，但缺乏实际威慑力。
- JP：口语化、街头感，与囚犯打成一片的松弛语气。
- 斯特凡妮：紧张、急于表现的新人语态。
- 幽默建立在“善意但能力不足”的制度荒诞上，情绪基调温暖但不回避监狱的沉重现实。

## 文化背景

- 法国监狱长期存在超押（surpopulation carcérale）与“惩罚 vs 改造”的公共辩论，本剧把这场辩论放进喜剧框架。
- 法语原题 Surveillant ! 即法国监狱狱警的正式职业名称（surveillant pénitentiaire），英文标题 Minimum Security 取自“低度设防监狱”这一概念，暗示该剧比一般监狱剧“温和”的视角。
- 被媒体类比为"监狱版 The Office / Brooklyn Nine-Nine"，更接近法式群像喜剧传统（如 Dix pour cent / Call My Agent!）。
- 实景拍摄于法国真实监狱，增强了伪纪录片质感与沉重底色。
