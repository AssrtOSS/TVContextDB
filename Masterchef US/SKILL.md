# Masterchef US translation context

# 《MasterChef US》（《厨艺大师》）字幕翻译背景

## 基本信息

- **英文名**：*MasterChef* / *MasterChef U.S.*
- **简体中文常用名**：《厨艺大师》；字幕中也可写作《厨艺大师（美国版）》。
- **其他地区译名**：台湾常见《厨神当道》；部分地区使用《我要做厨神》。
- **类型**：美国烹饪真人秀、竞赛类综艺。
- **首播**：2010年，FOX。
- **节目定位**：面向家庭厨师与业余厨师的全国性烹饪比赛，不以职业厨师为主要参赛对象。
- **制作背景**：改编自英国 *MasterChef* 节目格式，由 Franc Roddam 创制；美国版由 FOX、Endemol Shine North America、One Potato Two Potato 等参与制作。
- **拍摄空间**：主要在洛杉矶的摄影棚厨房进行，包含选手灶台、储藏室、冷藏区、评委台、阳台及餐厅式品尝区。

## 总体 premise

来自美国不同地区、职业和族裔背景的家庭厨师接受一系列限时烹饪挑战。评委从味道、技术、创意、熟度、摆盘和临场表现等方面评判菜品，选手逐轮晋级或淘汰，最终决出美国下一位 **MasterChef**。

常见赛程结构包括：

1. **海选 / Auditions**：选手制作代表菜，争取获得围裙。
2. **Mystery Box Challenge**：所有选手获得相同的神秘食材或任务，在限定时间内创作菜品。
3. **Elimination Test**：根据指定主题、食材或烹饪要求进行淘汰赛。
4. **Team Challenge**：分组完成餐厅服务、外景宴席或大型活动供餐。
5. **Pressure Test**：输掉团队挑战的选手进行高压力个人赛，通常有人被淘汰。
6. **免淘汰 / 优势奖励**：神秘箱获胜者可能获得免淘汰、选择食材、分组或指定对手等优势。
7. **半决赛与决赛**：剩余选手制作多道式菜单；最终冠军通常获得 **25万美元、MasterChef奖杯及称号**，部分季另有出版或厨具等奖励。

节目虽然是竞赛，但大量篇幅也会交代选手的家庭、移民经历、职业转型、经济压力、军旅经历和个人成长。因此字幕既要保留竞技紧张感，也要注意人物叙事中的情感语气。

### 姓名处理原则

- 评委和决赛选手首次出现时，可使用“中文译名（英文名）”或直接使用节目既有中文译名。
- 参赛者通常以名字互称，字幕不必每次加姓氏。
- 未有稳定中文译名的选手，保留英文拼写优于临时音译。
- **Chef** 在评委与选手之间通常译作“主厨”；评委自称或互称时不必机械翻译成“厨师”。
- 评委姓名中的重音符号可保留，例如 **Aarón Sánchez**；中文字幕中通常写作“亚伦·桑切斯”。

## 主要关系

- **Gordon Ramsay ↔ 参赛者**：主持人、主评委与被评判者；语气可严厉、直接，也会在关键时刻鼓励选手。
- **Joe Bastianich ↔ 参赛者**：评委与被评判者；更强调餐厅经营、商业可行性、味道和完成度，评论往往尖锐。
- **Aarón Sánchez ↔ 参赛者**：评委与被评判者；通常更关注香料、拉丁美洲料理传统、味道层次和个人背景。
- **Graham Elliot / Christina Tosi / Tiffany Derry ↔ 参赛者**：各季的评委关系；可根据具体季集判断其偏重的专业领域。
- **参赛者 ↔ 家人和朋友**：节目经常插入亲友采访、阳台助威和决赛现场支持。称呼中的 “Mom”, “Dad”, “baby”, “sweetheart” 应结合关系译为“妈妈”“爸爸”“宝贝”“亲爱的”等。
- **红队 / 蓝队等队伍**：团队挑战中按队伍分工；队长负责分配岗位、协调出餐和应对服务压力。

## 世界设定与节目空间

- **The MasterChef Kitchen**：节目核心厨房，选手拥有独立灶台、烤箱、刀具和共用食材区。推荐译为“厨艺大师厨房”或“《厨艺大师》厨房”。
- **Pantry**：储藏食材的区域，译为“储藏室”“食材区”或“食材库”。
- **Balcony**：已经安全晋级的选手观看挑战的位置，译为“阳台”。
- **Judges’ Table / Judges’ Room**：评委集中品尝、点评和宣布结果的区域，可译为“评委台”“评委席”。
- **Restaurant Challenge**：选手作为厨师、服务员或队长完成餐厅服务；不是普通的“餐厅挑战”之外的剧情设定，而是节目固定赛制。
- **Field Challenge / Outside Challenge**：离开摄影棚，在体育场、庄园、农场、军营、婚礼或大型活动现场烹饪。
- **Home cook / amateur cook**：统一译为“家庭厨师”或“业余厨师”。不要自动译成“厨师”，以免误解为职业厨师。
- **White apron**：海选晋级标志，译为“白围裙”。
- **Black apron**：部分赛制中的危险或淘汰标志，译为“黑围裙”。
- **MasterChef title**：冠军获得的节目称号，可译为“厨艺大师称号”或“美国下一位厨艺大师”。

## 说话风格

### Gordon Ramsay

- **特点**：高压、直接、情绪强烈，语速快，常用短句和命令句。
- **翻译方向**：保留冲击力，但避免每句话都翻成粗暴辱骂。
- **常见语气**：
  - “Come on!”：快点！/ 加油！
  - “Let’s go!”：出发！/ 动起来！
  - “What are you doing?”：你在做什么？
  - “This is raw.”：这还是生的。
  - “You’ve ruined it.”：你把这道菜毁了。
  - “Hands up!”：举手！
- **称呼**：对选手可用名字、亲昵称呼或直接下命令；选手回应通常使用“主厨”。

### Joe Bastianich

- **特点**：冷静、尖锐、重视味道和餐厅经营逻辑，常从商业、顾客体验和完成度角度评价。
- **翻译方向**：减少情绪化词汇，突出判断和讽刺感。
- **常见内容**：
  - 菜品能否在餐厅出售。
  - 菜品是否有足够辨识度。
  - 技术风险是否值得。
  - 菜品是否像“餐厅水准”。

### Aarón Sánchez

- **特点**：专业、鼓励性较强，常结合墨西哥料理、辣椒、香料、酸度及文化传承点评。
- **翻译方向**：语气可比 Ramsay 温和，但涉及技术时保持明确。
- **注意**：拉丁美洲料理名称、辣椒品种和家族饮食传统可能是人物身份的重要组成部分。

### Graham Elliot、Christina Tosi、Tiffany Derry

- **Graham Elliot**：常从创意、味道和现代摆盘角度评论。
- **Christina Tosi**：偏重甜点、烘焙、糖分、质地和甜咸平衡。
- **Tiffany Derry**：关注味道、技术、个人故事及菜品是否体现选手自身背景。
- 具体语气应以实际季集为准，不要把所有评委都翻译成 Ramsay 式的高压风格。

### 参赛者

- 参赛者多为家庭厨师，表达中经常出现：
  - “This means everything to me.”：这对我意义重大。
  - “I want to make my family proud.”：我想让家人为我骄傲。
  - “I don’t want to go home.”：我不想回家。
  - “This is my dream.”：这是我的梦想。
  - “I’m taking a risk.”：我在冒险。
- 采访段落通常是完整叙述，可稍微自然化；厨房现场则以短句、喊话、确认和倒计时为主。
- 家庭成员互相称呼时，注意美国英语中 **baby、babe、sweetheart、mom、mama** 的亲密程度，不要一律直译。

## 文化语境

- **家庭厨师文化**：节目强调“普通人也能通过训练和比赛成为顶级厨师”，选手的职业背景并不局限于餐饮业。
- **美国地域与移民背景**：各季常以州、地区、族裔、家庭传统和地方食材为人物标签。Southern、Midwestern、New England、West Coast 等区域概念应结合语境翻译。
- **个人奋斗叙事**：参赛常被描述为改变人生的机会，涉及职业转型、家庭责任、奖学金、军队经历、移民家庭和开餐厅梦想。
- **餐厅服务文化**：团队挑战中的 “service” 指高峰期餐厅出餐流程，重点是速度、协作、准确率和顾客满意度。
- **美国英语菜单用词**：  
  - appetizer = 前菜 / 开胃菜  
  - entrée = 主菜  
  - dessert = 甜点  
  不要按照法语原义把 entrée 翻成“入口”或“前菜”。
- **英美料理文化**：节目经常邀请英国、法国、意大利、墨西哥、日本等料理领域的嘉宾，或把选手带到庄园、体育场、军营和餐厅进行主题挑战。
- **王室、庄园及贵族语境**：涉及英国外景时，estate 通常是“庄园”，royal kitchen 是“王室厨房”，royal chef 可译“王室御厨”。这些场景属于特别挑战背景，不代表节目的常规拍摄地点。
- **宗教与家庭表达**：如 “I pray to the pressure cooker gods” 属于夸张玩笑，可译为“我向高压锅之神祈祷”，不必改成严肃宗教表达。
- **“go home”**：节目淘汰环节的固定表达，通常意味着“被淘汰”，可根据情绪译成“回家”“离开比赛”或“你的比赛到此结束”。

## 翻译统一建议

- 节目名统一使用《厨艺大师》，不要在同一集内交替使用《厨神当道》《我要做厨神》。
- **Chef** 作为选手对评委的称呼时优先译为“主厨”。
- **MasterChef Kitchen** 统一为“厨艺大师厨房”或“《厨艺大师》厨房”。
- **Mystery Box** 统一为“神秘箱”；**Pressure Test** 统一为“压力测试”。
- “Stop the clock” 优先译为“计时暂停”；“Hands up, utensils down” 优先译为“举手，放下厨具”。
- 烹饪专业词优先保证动作和结果清楚：  
  - reduce → 收汁 / 浓缩  
  - rest → 静置 / 醒肉  
  - sear → 煎至上色 / 煎封  
  - plate up → 摆盘 / 装盘  
  - doneness → 熟度  
- 评委批评应保留等级差异：  
  - “not bad” → 还不错  
  - “good” → 不错  
  - “very good” → 很好  
  - “brilliant / stunning” → 出色 / 惊艳  
  - “disaster” → 灾难 / 一塌糊涂  
- 历史 ASSRT 636262、636451、636452 中已出现并较稳定的译法包括“厨艺大师”“业余厨师”“白围裙”“黑围裙”“神秘箱挑战”“计时暂停”“主厨”“摆盘”“意式烩饭”“舒芙蕾”“高压锅”“收汁”“餐厅水准”等，可作为后续字幕的优先参考。
- 历史字幕中的个别姓名存在保留英文、临时音译和版本差异。遇到冲突时，应优先参考当季片头、FOX官方页面、节目字幕或多份公开资料，不要仅依据单一旧字幕决定译名。
