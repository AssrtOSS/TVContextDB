# The Kardashians translation context

# 卡戴珊家族 (The Kardashians) — 字幕翻译背景资料

## 节目基本信息
- 类型: 真人秀 / Reality Television
- 制作国家: 美国 (联合英国 Fulwell Entertainment)
- 原始语言: 英语
- 首播日期: 2022 年 4 月 14 日 (Season 1, Episode 1 "Burn Them All to the F*cking Ground")
- 播出平台: Hulu (美国本土)、Disney+ 国际版 (含台湾 / 香港繁体字幕，新加坡等地亦在 Star品牌下发行)
- 制作公司: Fulwell Entertainment、Kardashian Jenner Productions
- 执行制片: Kris Jenner、Kim Kardashian、Kourtney Kardashian、Khloé Kardashian、Kendall Jenner、Kylie Jenner、Ryan Seacrest、Ben Winston、Danielle King、Emma Conway、Elizabeth Jones
- 单集时长: 约 50 分钟
- 季 / 集结构: 每季固定 10 集；每周四更新一集；前四季每半年更一季，后续节奏略有变化
- 季开播时间一览:
  - Season 1: 2022-04-14 ~ 2022-06-16
  - Season 2: 2022-09-22 ~ 2022-11-24
  - Season 3: 2023-05-25 ~ 2023-07-27
  - Season 4: 2023-09-28 ~ 2023-11-30
  - Season 5: 2024-05-23 ~ 2024-07-25
  - Season 6: 2025-02-06 ~ 2025-04-10
  - Season 7: 2025-10-23 ~ 2025-12-25
  - Season 8: 2026-10 起- 前作关系: 本剧是《与卡戴珊一家同行》(Keeping Up with the Kardashians, E! 频道 2007–2021) 的续作 / 重启，主持人家族、Ryan Seacrest 出品等元素延续，但平台、团队、风格均换至 Hulu

## 人物关系
- 家族核心: 母亲 Kris Jenner 统一管理子女事业，被外媒称为 "Momager" (mom + manager)。Kris 前夫为前奥运十项全能冠军 Caitlyn Jenner (凯特琳·詹纳，2015 年公开变性并改名)，两人 2015 年离婚。
- 卡戴珊三姐妹 (Kim / Kourtney / Khloé): 同父同母，生父为已故律师 Robert Kardashian (罗伯特·卡戴珊，2003 年病逝)。母亲 Kris 再嫁 Bruce / Caitlyn Jenner 后生 Kendall / Kylie，因此卡戴珊三姐妹与詹娜两姐妹为同母异父关系，合称 "Kardashian-Jenner blended family"。
- 婚姻时间线: Kourtney 与 Travis Barker 于 2022 年意大利 Portofino 闪婚；Kim 与 Kanye West 2014 年结婚、2022 年离婚，剧中多季反复讨论两人关系。
- 子女关系: Kourtney 与 Scott Disick 育有三子 (Mason / Penelope / Rocky)；Khloé 与 Tristan Thompson 育有 True；Kim 与 Kanye 育有四子；Kylie 与 Travis Scott 育有 Stormi 与 Aire。
- 节目常驻工作关系: 家族团队包括律师、公关、化妆师、造型师，多人反复被点名 (尤其 Kris 助理团队)。

## 节目设定与世界观
- 主要场景: 洛杉矶 (Los Angeles)、卡拉巴萨斯 (Calabasas，家族聚居地)、棕榈泉 (Palm Springs)，并穿插纽约、东京、巴黎、迈阿密、墨西哥、印度等差旅场景。
- 标志性空间: Hidden Hills / Calabasas 豪宅、Kris 的 Hidden Hills 主屋 (S6–S7 出现出售剧情)、金在 Calabasas 的 SKIMS 办公室 / 试衣间、考特妮的 Poosh 总部、凯莉的 Kylie Cosmetics 办公室与 glam room、Kim 的法学课程 / 律所实习点、Met Gala 纽约大都会博物馆、戛纳 / 巴黎时装周、Coachella 音乐节等。
- 行业语境: 时尚 (fashion, runway, campaign, Vogue, designer)、美妆 (beauty, foundation, lip kit, mascara)、内衣塑身 (shapewear)、房地产 (real estate, listing, escrow)、法律 (S6–S7 重点：law school, bar exam, trial, testimony, verdict)、社交媒体 (Instagram / TikTok 现实同步传播)、真人秀制作 (production, edit, storyline) 等。
- 叙事结构: 半纪录片式真人秀，每集交织 3–5 条 storyline；典型场景有 confessional (单人面对镜头独白) 与 family sit-down (家族聚餐座谈)。

## 整体剧情主线 (横跨多季)
节目无传统剧本主线，围绕真实生活滚动展开，主要 story arc 如下:
- 金的"第二职业线": 从时装 /香水 / SKIMS 扩展到法律学习 (S6 起重点跟拍)，并在 S7 回到 2016 年巴黎被劫案的庭审作证。
- 考特妮的"婚礼 + 育儿"线: S1–S2 筹备并完成与 Travis 的婚礼；S3–S4 聚焦婚后生活与新生儿 Rocky；S5–S7 转向与科勒的家族矛盾。
- 科勒的"育儿 + 恋爱"线: True 的抚养、与 Tristan Thompson 反复复合又分手、S7 出现新的恋爱线。
- 凯莉的"美妆帝国"线: Kylie Cosmetics 创立与十周年 (S7)、Travis Scott 之后与 Timothée Chalamet 的高调恋情 (S6 起)。
- 肯达尔的"模特 / 恋情"线: 模特事业、与 Devin Booker / Bad Bunny / Hailey Bieber 友情线。
- 母亲的"管理线": Kris 持续撮合子女事业，处理公关危机，S6–S7 推进出售主屋、规划新家庭空间。
- 全季结构: 每季首集通常作 "season reset"，中段 1–2 集聚焦单一主线 (婚礼 / 庭审 / 品牌发布 / Met Gala)，后段以家族聚餐高潮收尾。

## 说话风格与文化背景
- 整体语气: 私人化、情绪化、节奏短，夹杂 "like" (像)、"literally" (简直) 等口语填充词，字幕建议轻量化处理。
- Kim: 法律术语 (court / trial / verdict / testimony, S6–S7 大量出现)、商业计划 (launch / retail / campaign)、育儿话题，常用 "I'm literally so excited" 类情绪化句式。
- Kourtney: 风格寡淡，强调 organic / holistic (有机 / 整体)、wellness、clean beauty、POOSH 品牌语汇。
- Khloé: 直接、强势、爱用夸张表达 (literally、the most、in the whole entire world)，话题集中于育儿、单身生活、家庭矛盾。
- Kris: 措辞公关化，常用 "the girls" / "my kids" / "momager" 自称，夹杂商业决策与家族会议口吻。
- Kendall: 偏冷静，模特行业术语 (campaign / runway / brand ambassador / booking / shoot) 集中。
- Kylie: 偏安静，话题围绕 Kylie Cosmetics 产品 (foundation / lip kit / mascara / launch) 与 Stormi 育儿。
- Scott Disick: 戏谑，爱用 "I literally died" 类夸张表达，与 Kim 的互动常出现戏仿口吻。
- 文化背景: 美国西海岸富人文化 / 名人文化 / 社交媒体文化 (Instagram、TikTok 现实同步)，与 K-pop (S2–S3 金、Kris 对 BTS、Blackpink 的关注)、Calabasas 地产语境、Met Gala 时尚语境、Coachella / 超级碗 (Super Bowl) 等联动；节目中 "girls' trip" / "family trip" / "LA dinner" 等场景可直译为 "姐妹出游" / "家族出游" / "晚宴"。
