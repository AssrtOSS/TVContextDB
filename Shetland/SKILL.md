# Shetland（设得兰 / 设得兰谜案）字幕翻译背景

## 作品身份核验
- 剧名：Shetland（英文原名），BBC One 播出的苏格兰犯罪剧（crime drama / detective fiction），不是电影。
- 原著：改编自 Ann Cleeves（安·克利芙丝）的 "Shetland" 系列小说（首部《Raven Black》/《黑渡鸦》），首季即改编自《Raven Black》。
- 首播：2013 年 3 月 10 日，BBC One；由 ITV Studios 与 BBC 联合制作，拍摄地多在苏格兰大陆（格拉斯哥、Argyll 等）及设得兰实地取景。
- 季/集结构（持续播出中）：第 1 季 2 集（两集一个故事），第 2 季起每季 6 集、多为 2 集一案的三段式或一季一案长线；第 3–7 季各 6 集；第 8、9 季各 6 集；截至 2024/2025 已播出第 9 季并续订。夜用「季 / Series」「集 / Episode」，不用美式 Season 译法时保持「第 X 季」。
- 中文片名：常见「设得兰」「设得兰谜案」「设得兰群岛」；字幕沿用既有译名，保持全片统一。

## 整体剧情前提（跨季，不限一季一案）
主角 Jimmy Perez 探长在妻子去世后带着继女 Cassie 回到故乡设得兰群岛任职。群岛地处苏格兰最北端、孤悬北海，社区封闭、人口稀少、彼此熟识，几乎「没有秘密能藏住」。每季以一桩或多桩谋杀为线索，层层揭开平静海岛表象下的旧怨、家族隐秘、土地与油气开发带来的利益冲突，以及「外来者 vs 岛民」的张力。Perez 的本地出身既是优势也是负担——他认识几乎每一个嫌疑人。剧集基调冷峻、缓慢、重氛围，风景（峭壁、荒原、海、多变天气）本身即是叙事的一部分，属典型「Nordic / Scottish noir」。

## 主要人物与关系（英文名 — 中文译名对照）
以下角色名为跨季 recurring 人物。中文为通用音译惯例（本轮检索未取得字幕组/中文维基的「既定译名」实证，ASSRT 历史字幕亦为空），首次出现时可括注英文，之后统一沿用，勿在不同季间换字。

- DI Jimmy Perez（吉米·佩雷斯 探长）— 主角，设得兰本地人，丧偶，温和内敛、善于倾听。第 1–8 季由 Douglas Henshall 饰演；第 9 季起由 Ashley Jensen 接替主角。
- Cassie Perez（卡西·佩雷斯）— Perez 的继女，青春期少女，与继父的亲情线贯穿多季；生父为 Duncan Hunter。
- DS Alison "Tosh" McIntosh（艾莉森·「托什」·麦金托什 警长）— Perez 的搭档，来自外地，逐步融入岛民社群；后期升任 DI。绰号 Tosh 保留音译「托什」。
- DC Sandy Wilson（桑迪·威尔逊 警员）— 本地年轻警员，憨厚、熟悉岛务。
- Sgt / DI Ruth Calder（露丝·考尔德）— 第 9 季起与 Perez 搭班的本地出身探长（Ashley Jensen 饰）。
- Duncan Hunter（邓肯·亨特）— Cassie 的生父，与 Perez 关系紧张，反复出现。
- Cora McLean / 各季案件人物 — 逐案角色按当季字幕表统一，不在此强行固化。
- Procurator Fiscal（检察官 / 苏格兰检控官）、Pathologist（法医）等职能称谓按苏格兰司法体系译，见下。

关系要点：Perez–Cassie 为继父女（非亲生）；Perez–Tosh 为师徒式搭档；Perez–Duncan 为生父与继父的微妙对立；「岛上人人相识」决定了大量对白含「谁是谁的谁」的亲属/邻里指代，翻译时需保留这层熟人社会语感。

## 世界设定
- 地理：设得兰群岛（Shetland Islands / Shetland），苏格兰最北，距挪威/奥克尼比距伦敦更近；首府 Lerwick（勒威克），外岛如 Unst（安斯特）、Yell、Fair Isle、Foula、Scalloway 等常作为案件地点。
- 历史/文化底色：维京—北欧遗产深厚（比苏格兰本土更「北欧」），有 Up Helly Aa（维京火节）、Norn 语遗痕、地名多为古诺尔斯语来源。岛民认同常是「Shetlander」先于「Scottish」。
- 产业与议题：渔业、养殖（三文鱼）、石油/天然气（北海油气）、风电与土地权属、人口外流、渡轮与天气决定的交通隔绝，常构成案件动机。
- 天气与光：漫长冬夜、短日照、风暴、大雾；「天气」频繁出现在对白与调度（航班/渡轮停摆、无法离岛），翻译不可弱化其叙事功能。

##  recurring 术语与中文处理
- Shetland / Shetlander → 设得兰（群岛）/ 设得兰人、岛民；避免写成「设德兰」「谢特兰」。
- mainland（the mainland）→ 苏格兰本土 / 大陆（岛上人指苏格兰本岛，非泛指欧洲大陆），需按语境点明。
- Lerwick / Scalloway / Unst / Fair Isle 等 → 音译并保留英文地名括注一次；统一用字。
- DI / DS / DC / Sgt → 探长 / 警长 / 警员 / 警长（警衔按英制，Procurator Fiscal 译「检控官/苏格兰检察官」，不走英美「DA/地方检察官」）。
- Procurator Fiscal → （苏格兰）检控官；苏格兰无陪审团部分程序与英格兰不同，勿套用美国庭审词汇。
- Fiscal / Sheriff Court / High Court → 检控官 / 郡法院 / 高等法院，保留苏格兰司法体系特征。
- croft / crofter → 小农场（佃农小块地）/ 小农；具苏格兰高地—群岛特定含义，不译普通「农场主」了事。
- Up Helly Aa → 维京火节（可括注 Up Helly Aa），文化专有项保留。
- peat / burn / loch / voe / firth → 泥炭 / 溪流 / 湖（苏格兰 loch）/ 小海湾（voe，设得兰用语）/ 海湾；地理通名按苏格兰习惯，不混用英格兰词。
- bairn / ken / dinna / aye / wee / lass / lad 等苏格兰/设得兰口语 → 见「语言风格」。
- 「the mainland」「off the island」「the boat / ferry」「the weather's closing in」→ 固定译法保持一致，构成 recurring 语汇。

## 说话风格与口音
- 对白为苏格兰英语，夹杂 Scots 与设得兰方言词汇（ken=知道、bairn=小孩、wee=小、aye=是、dinna=不要、nae=不、lass/lad=姑娘/小伙、bonnie=好看、dreich=阴湿天气）。字幕以标准普通话书面语转写，不强行用北方方言或拼音模仿口音；通过「口语化、短句、略带乡土感的措辞」体现，可在必要时以脚注/括注点明双关。
- 岛民间对白含蓄、少直抒、大量留白与「话里有话」；Perez 以平静、低声、共情式问话著称，避免译成咄咄逼人的美式审讯腔。
- 警局程序对白严谨、克制；情感戏克制内敛，勿过度煽情加字。
- 绰号（Tosh 等）、敬语与职称（DI、sir、Fiscal）保持一致；「sir」按英警语境译「长官/探长」而非「先生」。
- 涉及维京/古诺尔斯地名、节庆词首次出现可加极简括注，之后不再重复。

## 文化背景提示
- 北欧（维京）而非凯尔特—苏格兰高地是设得兰身份核心；火节、船、地名皆源于此。
- 社群「熟人社会」：嫌疑人与警员常是亲友邻里，保密与袒护是常见动机，翻译须保留「都认识彼此」的语用前提。
- 苏格兰司法与警政体系独立于英格兰（检控官、无「验尸官 coroner」美式设定、郡/高等法院），机构名不可换成美国或英格兰叫法。
- 宗教（苏格兰教会/自由教会）与社区保守风气、对外来者（incomers）的微妙态度为多季潜台词。
- 风景、天气、隔绝感是「角色」，片头/空镜/天气对白不宜精简掉氛围信息。
- 改编自 Ann Cleeves 小说，整体属「苏格兰黑色 / Nordic noir」慢热推理，节奏偏沉稳，字幕亦宜克制、不抢戏。

## 译名一致性原则（可复用）
1. 全系列固定：角色、地名、警衔、机构名、专有节庆/方言词一经确定不得跨季改字；建立术语表。
2. 首次出现「中文（English）」括注，之后仅用中文；地名/文化专有项同理。
3. 优先沿用片方/既有官方或字幕组既定译名；本轮无 ASSRT 历史字幕（< ID 800000）可比对，故上文音译按普通话通用惯例给出，若拿到既定字幕表应以其为准覆盖。
4. 方言不方言化：用标准书面中文 + 口语节奏体现，不造字、不用谐音抖机灵。
5. 多季一案与单季多案并存，背景介绍不绑定某一季剧情。
