# Trying translation context

# 《尝试》（Trying）字幕翻译背景

## 基本信息

- **英文名**：*Trying*
- **常用中文名**：**《尝试》**
- **其他中文名**：**《家·多点尝试》**、**《而立人生》**
- **类型**：英国喜剧／剧情喜剧，带有爱情与家庭题材。
- **主创**：Andy Wolton（安迪·沃尔顿）
- **制作**：Apple TV+ 与 BBC Studios 联合制作。
- **主要场景**：英国伦敦北部 Camden（卡姆登）及周边。
- 全剧核心并非单一的生育或领养故事，而是围绕 Nikki、Jason 及其亲友，描写成年人建立家庭、承担责任、处理亲密关系和逐渐成熟的过程。

## 整体剧情 premise

Nikki Newman（妮琪·纽曼）和 Jason Ross（杰森·罗斯）是一对住在伦敦的三十多岁情侣，渴望成为父母，却难以自然受孕。经过对 IVF（体外受精／试管婴儿）前景和费用的考虑，他们转而尝试领养。

前两季主要描写他们接受领养评估、寻找合适孩子以及经历匹配失败的过程。后来，他们遇到亲兄妹 Princess 和 Tyler，并努力让两个孩子不被分开。第三季聚焦临时照护、家庭磨合、亲生家属的意见和最终的收养听证。第四季时间跳跃六年，Nikki 与 Jason 已成为有经验的收养父母，Princess 进入青春期并开始寻找自己的生母，家庭身份、亲生家庭与养育关系再次成为主要矛盾。

剧集的喜剧感来自日常失误、尴尬社交、英式冷幽默和朋友家人的荒诞行为；情感核心则是“成为父母并不等于立刻懂得如何做父母”。

## 家庭与关系结构

- **Nikki 与 Jason**：长期伴侣，前期未婚；两人共同经历领养评估，后成为夫妻。
- **Princess 与 Tyler**：亲兄妹，关系紧密。剧中反复强调不能轻易将他们分开。
- **Nikki 与 Karen**：姐妹，关系亲密但会直接争吵；Karen 常充当现实主义的提醒者。
- **Jason 与 Freddy**：好友。Freddy 的生活方式与 Jason 的责任感形成对比。
- **Princess、Tyler 与 Bev**：孩子、养育家庭和亲生家属之间的关系构成第三季的重要情感冲突。
- **Princess 与 Kat**：生母与女儿的身份关系是第四季的重要线索。
- Nikki 与 Jason 的朋友、双方父母和亲属共同构成一个“support network”（支持网络），剧中家庭概念并不限于血缘关系。

## 世界设定与文化背景

### 英国伦敦日常生活

- 故事发生在当代英国伦敦，尤其是 Camden（卡姆登）一带。
- **flat** 指英国式公寓／住宅，通常译为“公寓”或“家里”，不必译成“套房”。
- **pub** 是英国酒吧兼社交场所，常用于聚会、葬礼后的守灵聚会、朋友聊天等。
- 人物说话常涉及房租、搬家、通勤、工作压力、托儿、学校和家庭经济状况，整体是普通中产及工薪阶层的生活语境。

### 英国领养制度语境

剧中的领养流程不是简单的“选孩子”，而是包含多个环节：

- adoption agency：领养机构
- social worker：社工
- adoption assessment：领养评估
- adoption panel：领养评估委员会／领养审核委员会
- matching：匹配
- placement：安置／照护安排
- temporary placement：临时安置
- adoption hearing：领养听证／收养听证
- birth mother：生母
- biological family：亲生家庭
- foster care：寄养照护

具体译法可根据对白语境调整。“adopt”在剧中通常译为“领养”；当语境强调法律程序完成后，也可译为“收养”。

### 足球文化

足球是 Jason 与孩子建立关系的重要媒介，也是英国身份和家庭互动的一部分。

- **Arsenal**：阿森纳
- **Spurs／Tottenham**：热刺／托特纳姆热刺
- **football**：英式足球；在中文语境中通常直接译为“足球”，不要译成“橄榄球”。
- Jason 支持 Spurs，而 Tyler 支持 Arsenal。相关对白常以球队立场制造家庭喜剧。

### 婚礼与社交习俗

- **stag do**：单身汉派对／新郎婚前派对
- **hen do**：女子婚前派对／新娘婚前派对
- **best man**：伴郎
- **bridesmaid**：伴娘
- **registrar**：婚姻登记官；英国婚礼语境下也可指主持民事婚礼的登记官。
- 婚礼、葬礼、pub 聚会、学校活动和家庭聚餐常被用来推动人物关系变化。

## 人物说话风格

### Nikki

- 语速较快，情绪外露，容易在兴奋、焦虑和冲动之间切换。
- 常用夸张表达来掩饰不安。
- 说话亲近、直接，面对孩子时会努力表现得成熟，但经常暴露出经验不足。
- 翻译不宜过度书面化，应保留自然、热心又有些慌乱的感觉。

### Jason

- 语气温和、谨慎，喜欢分析问题和解释细节。
- 前英语教师身份使他偶尔显得讲究措辞，甚至有些过度理性。
- 面对情感问题时容易尴尬或绕弯，笑点经常来自认真态度与混乱现实之间的反差。
- 不宜翻译得过于油滑或强势。

### Karen

- 直接、尖锐、现实，常说出其他人不愿说的话。
- 对 Nikki 亲密，但不会持续使用温柔安慰式表达。
- 可适当使用短句和略带讽刺的口吻。

### Scott

- 夸张、兴奋、自信过头。
- 经常提出宏大、欠缺可行性的计划。
- 他的台词可以保留自我感觉良好和一本正经的荒诞感。

### Freddy

- 前期偏自我中心、轻浮，后期逐渐显露出忠诚和善意。
- 与 Jason 的对话常有朋友间的打趣、挖苦和互相拆台。
- 不要把他的玩笑全部译成恶意辱骂。

### Princess

- 年幼阶段聪明、敏感，观察力强，有时比养父母更成熟。
- 青少年阶段更直接、更有防备心理，涉及生母时情绪复杂。
- 她的台词应体现年龄变化，避免始终使用幼稚的儿童口吻。

### Tyler

- 年幼、活泼，表达通常比 Princess 更直接。
- 语言可更简单、更具即时反应。
- 与 Jason 的足球相关对白具有亲子磨合和身份认同的双重意味。

### Penny 与社工角色

- Penny 的语言通常专业、克制，但并不冷漠。
- 领养程序相关对白要保持清晰准确，避免为了口语化而模糊法律或社会服务概念。

## 翻译注意事项

- **片名的多义性**：*Trying* 不只指“尝试怀孕”，也指尝试领养、尝试成为父母、尝试维持关系和尝试成长。
- **Princess 是人名**：首次出现时可写作“普林塞斯”，后续保持统一；不要在普通对白里擅自改成“公主”。
- **adopt 与 foster 要区分**：临时照护、寄养和正式领养不是同一概念。
- **英国英语与美国英语有差异**：如 flat、football、mate、cheeky、fancy dress、hen do、stag do 等。
- **保留英式幽默的轻描淡写**：人物经常用平静语气说出尴尬、荒诞或感人的内容，不宜全部翻译成强烈情绪。
- **家庭成员的称谓要按关系处理**：Princess 和 Tyler 对 Nikki、Jason、Bev 的称呼变化具有剧情意义，应保持前后一致。
- **避免过度拔高**：本剧虽涉及不孕、领养、亲生家庭、青春期和社会服务，但基调始终是生活化喜剧，不应把普通玩笑翻译成严肃说教。
- **足球俱乐部名称要统一**：Spurs 译作“热刺”，Arsenal 译作“阿森纳”。
