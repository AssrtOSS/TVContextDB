### 世界设定
- 现代墨西哥城（Mexico City），经常出现街头追逐、市政与政界高层场景
- 改编自当代墨西哥权钱交易与新闻自由的现实议题：记者因报道权贵而被威胁、绑架、灭口
- 2014 年原小说设定为 PRI 执政时期；剧集更新至 2026 年，纳入女性总统就任、社交媒体/数字平台对政治的影响等当代要素
- 剧中平行现实设定：墨西哥仍属全球对记者最危险的国家之一（无国界记者组织数据点明"自 2000 年以来逾 150 名记者遇害、28 名失踪"）

### 关系要点
- 核心四人组之间是"发小 / 童年盟友"，被称作 Los Azules（The Blue Crew / 蓝色四人组），既是情谊也是共谋结构
- Tomás 因一次未经核实的视频发布，把整个四人组拖入险境
- Amelia 因党内地位受威胁，需要在政治盟友与四人忠诚之间二选一
- Jaime 与父亲有公开裂痕，且被警告离境，自带"被困者"压力
- Mario 凭学术资源协助调查，与 Tomás 形成情报搭档
- Mictlán 长期作为四人组的隐藏一员，经历绑架后转为反攻主导者
- Tomás 与 Amelia 在调查过程中越走越近
- Viridiana、Nico 与 Jimena 三人形成外围调查小组，被 Mictlán 招募进反击计划

### 总体剧情
一段被泄露的视频，把四个童年挚友拖进一场横跨墨西哥政界、军方与娱乐圈的腐败漩涡。电视记者 Tomás 偶然发出受害女演员 Pamela Dosantos 命案前的影像，画面牵涉国防部长级别的人物；为求自保与查明真相，Tomás 召集发小 Amelia（女议员）、Jaime（安保专家）、Mario（学者）共同调查，连同 Mictlán 一起被卷入当局监视、绑架、谋杀与勒索交织的连环危机。随调查深入，四人被迫直面各自最深处的秘密、野心与恐惧——他们发现"圈越紧，藏得越黑；维系他们的忠诚和他们守护的秘密一样脆弱"。全剧 8 集为完整第一季，悬念集中于：友情在真相面前能否存活？而那个圈子，到底谁在利用腐败，谁才是真正的腐败者？

### 固定术语与中文译法
- Los corruptores / The Corruptors（小说原名）— 《腐败者》；电视剧改名为 El Círculo / Inside The Circle
- Los Azules / The Blue Crew — 蓝色四人组 / 蓝色小队 / 蓝色一伙（核心四人组群称）
- El Círculo — "圈" / "小圈子" / "权力圈"（剧名核心意象；可直译作"圈子"或意译作"小集团"）
- chantaje — 勒索 / 要挟
- filtración（视频/数据泄露）— 泄露、流出、走漏
- caso Pamela Dosantos — 帕梅拉·多桑托斯案（贯穿全季的命案核心）
- Secretario de Defensa / 国防部长 — 剧中被录像牵涉的最高级别官员
- periodista — 记者；剧中反复点出"为了比这更小的事，他们就会杀记者"
- círculos de poder / 权力圈 — 借用剧名本身的隐喻
- "el círculo protege" 或"el círculo se cierra" 类语义 — "圈里人相互包庇" / "圈子越收越紧"
- coartada — 不在场证明 / 托词
- montaje — 构陷 / 栽赃（注意与电影术语"蒙太奇"区分，按剧情语境使用）

### 说话风格与文化语境
- 语言：墨西哥西班牙语（es-MX / Spanish (Latin America)）；字幕定位为"拉美西语"
- 剧作风格：黑色政治惊悚，节奏紧凑，对白偏冷峻、克制；偏向成人化道德权衡而非高调动作戏
- 社交语态：四人之间用西语昵称互称（如 Tomás、Tomasito；Amelia 偶尔被叫 Meli），外人面前切换为更正式的"您"
- 政治语汇：常用PRI、Secretaría de Defensa、Congreso / 议会 等墨西哥本土政治术语；剧中暗含对执政党、军方与媒体共生腐败的批评
- 新闻业文化：记者常以"匿名信源"、"未核实即发稿"等新闻伦理冲突推进剧情
- 社交媒体生态：剧集刻意呈现 X / Twitter 时代一条视频如何瞬间触发危机，台词可能含"se hizo viral"（迅速走红 / 病毒式传播）
- 行业梗与致敬：Lemon Studios 在墨西哥类型剧（thriller / narco 系列）领域有持续输出，本剧可参考其既往作品《Matando Cabos》《La cocina》同款的冷峻质感

### 翻译建议要点
- 角色名优先使用上表所列"英文名 / 中文译名"对照，混排时保持一致
- "Los Azules / The Blue Crew" 建议在首次出现时译为"蓝色四人组"，后文简称"四人组"或保留"Azules"
- "El Círculo" 作为剧名译为《圈内危局》或保留通用译名《致命权力圈》；台标/字幕标题建议使用《致命权力圈》以贴合华语流媒体观众
- "Pamela Dosantos" 译作"帕梅拉·多桑托斯"；首次出现可加注"女演员"
- "Mictlán" 直译为"米克特兰"或音译"麦克特兰"；保留神秘昵称感，不必强行意译（其名源自阿兹特克冥界"Mictlán"，剧中可点出文化渊源）
- 涉及墨西哥政府机构名时，建议使用"国防部 / 国防部长 / 议会 / 国会议员"等通用中文译法，必要时附原文
- 西语脏话与亲密称呼（如"cariño""amor""mi vida""cabrón""wey / güey"）按成人口吻处理，保持原剧张力
- 注意区分"circulo de tiza"（粉笔圈，源自布莱希特剧作，与本剧无关）等同形异义词
