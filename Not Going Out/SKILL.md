# Not Going Out translation context

# Not Going Out (别出去) — 字幕翻译背景资料

## 基本信息

- 英文原名：Not Going Out（已核实：BBC One 情景喜剧，2006年10月6日首播，非电影，无同名干扰项）
- 通行中文译名：别出去（豆瓣等平台通用译名；直译“不出去玩/不出门”，指主角 Lee 的宅男生活方式）
- 类型：摄影棚多机位情景喜剧（studio sitcom），每集约30分钟
- 播出平台：BBC One；制作方 Avalon Television
- 主创/主演：Lee Mack（编剧兼主演，与 Andrew Collins 等共同创作）
- 规模：截至2023年圣诞特辑播出第100集；第14季2025年播出；第15季（6集）已续订，预计2026年播出。是英国目前在播的最长寿情景喜剧（按季数计居历史第二，仅次于 Last of the Summer Wine）。2009年第三季期间曾被 BBC 取消，因观众反弹而恢复。

## 世界观与场景设定

故事主要发生在伦敦。第1—7季为“码头区（London Docklands）时期”：核心场景是 Lee 与房东合租的公寓，以及他们常去的酒吧。第8—13季：Lee 与 Lucy 婚后搬到萨里郡 Walton-on-Thames，围绕三个孩子的家庭生活展开。第14季起：孩子们上大学后（空巢），夫妻搬入乡村住宅，场景转为新房子及周边。传统上每年有圣诞特辑。

## 整体剧情前提

Lee 是一个来自兰开夏郡、毫无上进心的懒散青年，频繁换工作，靠房东的善意生活。全剧贯穿他与其房东/挚爱之间“到底能不能在一起”（will-they-won't-they）的主线：

- 第1季：Lee 与加州房东 Kate 合租，两人渐生情愫，但 Kate 是 Lee 挚友 Tim 的前女友，关系尴尬。季末 Kate 回美国。
- 第2—6季：Tim 的妹妹 Lucy（在苏黎世打拼多年的成功职场女性）买下公寓成为新房东，Lee 对她展开长期追求，期间穿插 Lucy 的男友 Guy、清理员 Barbara、Tim 的女友 Daisy 等人。
- 第7季：Lee 求婚成功，两人结婚。
- 第8—13季：八年的时间跳跃，夫妻养育三个孩子，与邻居 Toby、Anna 两家互动。
- 第14—15季：空巢期，夫妻搬至乡村，鸡飞狗跳的二人世界。

## 人物关系图

- Lee ←挚友→ Tim；Lee ←房东/暗恋→ Kate（第1季）；Lee ←房东/追求/夫妻→ Lucy（第2季起）
- Tim ←兄妹→ Lucy；Tim ←前情侣→ Kate；Tim ←情侣→ Daisy
- Toby ←夫妻→ Anna；Geoffrey/Wendy 为 Tim、Lucy 之父母；Frank 为 Lee 之父

## 常用术语与中文译法建议

- landlady — 房东（女），剧情核心称谓，勿译作“女地主”
- flat / flatmate — 公寓 / 室友（英式，勿用 apartment）
- round / pint / pub — 酒吧 / 一品脱（啤酒）/ 去酒吧喝酒（“get a round in”＝请大家喝一轮）
- sit-com / studio sitcom — 情景喜剧（现场观众录制）
- will-they-won't-they — “到底成不成”的暧昧关系
- Christmas Special — 圣诞特辑
- The Docklands — 伦敦码头区（第1—7季场景）
- Henley — 亨利镇（Tim 的家乡）；Walton-on-Thames — 泰晤士河畔沃尔顿（第8—13季居所）
- Zurich — 苏黎世（Lucy 之前工作地）
- headhunter — 猎头（Lucy 的职业）
- accountant — 会计师（Tim 的职业）

## 语言与说话风格

- Lee（Lee Mack 本人风格）：语速极快的一句话笑料（one-liner）、抬杠、毒舌吐槽；用玩笑化解一切严肃场合，从不认真，这是他惹祸的根源。
- Tim：演员 Tim Vine 是著名的双关语（pun）大师，Tim 的台词布满冷双关和老爹笑话（dad jokes），翻译时应尽量保留双关或在译注中处理。
- Lucy：主要担当“吐槽役”（straight woman），对 Lee 的胡闹表示无奈和讽刺，职场用语干练。
- Daisy：答非所问、逻辑清奇、轻信他人。
- Barbara：语无伦次、自说自话的怪人。
- Anna：刻薄、居高临下、面无表情的冷幽默。
- 整体节奏：快节奏密集笑点（gag-dense），台词含大量英式俚语和文字游戏。

## 文化背景

- 英式摄影棚情景喜剧传统：现场观众笑声、多机位、舞台化布景，笑点密度高、以对白驱动。
- 英国酒吧文化是重要社交场景，多集围绕 pub 展开。
- 健康饮食梗：加州人 Kate 的素食/有机食物被 Lee 视为“令人作呕的健康食品”，是美国加州刻板印象与英式懒人饮食的碰撞。
- 阶级与家庭刻板印象：Geoffrey 对儿子的失望、Anna 的势利，反映英式家庭与阶层幽默。
- 圣诞特辑是英剧传统，常含家庭团聚情节。
